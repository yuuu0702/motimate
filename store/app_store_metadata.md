### アプリ説明（4000文字以内）
```
【MotiMateとは】
MotiMateは、スポーツチーム、勉強会、文化サークルなど、あらゆる種類のサークル活動をサポートする包括的なアプリです。メンバーのモチベーション管理から実用的な機能まで、サークル運営に必要なすべてを一つのアプリで提供します。

【主な機能】

📊 モチベーション管理
• 活動前後の気分をエモーション選択で簡単記録
• 個人とチーム全体の参加パターンを美しいグラフで可視化
• 時系列でのモチベーション変化を分析し、改善点を発見

🏀 活動管理
• 練習や活動予定の一元管理
• メンバーの参加可否をリアルタイムで把握
• 過去の活動データを蓄積・分析して次回に活かす

👥 メンバー管理
• 複数のサークルへの同時参加が可能
• 作成者、管理者、メンバー、ゲストの4段階権限システム
• 簡単なタップでサークル間を切り替え

🔔 通知機能
• 重要な情報をリアルタイムでプッシュ通知
• サークル別の専用通知システム
• 個人の好みに合わせた詳細なカスタマイズが可能

🎨 カスタマイズ
• ダークモード・ライトモード完全対応
• サークルごとのアイコン・カラーテーマ設定
• アクセシビリティ機能でスクリーンリーダー完全対応

【こんな方におすすめ】
✓ スポーツチームのコーチ・キャプテン
✓ 勉強会・読書会の主催者
✓ 文化サークルのリーダー
✓ 社内サークルの運営者
✓ 地域コミュニティの活動に参加している方

【利用シーン】
• 部活動の練習参加率向上
• 勉強会の継続的な学習習慣形成
• 文化サークルの創作活動モチベーション維持
• 社内イベントの企画・運営
• 地域活動の活性化

【セキュリティ・プライバシー】
Firebase認証による安全なログイン、Firestore Security Rulesによるデータ保護、SSL/TLS通信暗号化で、あなたの大切なデータを守ります。

【料金】
基本機能は完全無料でご利用いただけます。

今すぐダウンロードして、あなたのサークル活動をもっと楽しく、もっと充実させましょう！
```
